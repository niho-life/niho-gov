# 目的
町のリビングを運営するNIHOがオンラインのメディアとして、街の情報の集約拠点を目指している
そのために、まず鎌倉市の財政情報をみやすくしたい。
現状の予算の歳出詳細はPDF化されていて検索もできないので、それをテキストで見えるようにして、鎌倉市民が、鎌倉市はどんな費用にいくらを使っているのかをわかるようにしていきたい。

#設計方針
ある程度テキストでPDFから文字情報を抽出できるので、pdftotextを使う方法で大半のテキストを抽出する。OCRよりも精度が良かった。


# 実装したい機能
＜直近編＞
- 鎌倉市民（NIHOオンラインメディア閲覧者）が鎌倉市民の歳出詳細を見れるようにする
  - まず全体の区分として、議会費・消防費などの大きな費目単位で、何がいくらなのかをぱっとわかるようにしたい。
  - その上で、その費目の具体項目をそれぞれいくらなのかを見たい。さらにその具体項目の詳細な予算内訳も見たい。
  - 大きい金額順に事業費を並び替えられる
  - 検索欄から文字で検索したらそれに関連する事業費・予算内訳の項目を表示する
  - 予算詳細をCSVなどでエクスポートして自分の手元で分析にも使えるようになる

＜将来編＞
- 経年の変化を比較できるようにする
- その費用をかけて実施した事業の結果のURLに飛んでいけるようにする
  - そのためにそれぞれの事業の詳細ページのURLを見つけて紐づける
- チャットbotに聞いたら、このJSONファイルなどをRAGのデータベースとして使って簡単な回答をしてくれる。JSONファイル内にない場合は別途Web上を検索してくれる
  - 例えば、藤沢市と比べて一人当たりの教育費用は多いの？などの質問にchatbotが調べて答えてくれる

# 達成したい結果

- 鎌倉市民が、鎌倉市が何にお金を使っているかの全体像を掴める
  - 何が最近増えてきたかも見える
  - 自分が関心のある予算項目はいくら程度を使っているのかがわかる。
    - 鎌倉市は教育費用にいくら使っているのかしら。藤沢市と比べて多いのかしら、など





# 修正したい機能
- 現状のJSONは例えば、「	会 計 年 度 任 用 職 員 費 用 弁 償」のように、半角スペースなどスペースが無駄に入っている。１つのテキストに空白は入らないはずなので、空白を削除して正しい単語にしたい。


# 財政全体像（概要）セクション

## 目的
`議会費` などの「事業費別詳細」とは別に、まず **財政の全体像（歳出の俯瞰）** を見れるセクションを用意する。

- 款別（議会費・民生費…）の金額・構成比・前年差がパッと分かる
- 款別の内訳（性質別：人件費/物件費/扶助費…）が比率で分かる

## 入力データ（PDF）
- `NIHO/gov/naiyo-setsumei.pdf`（8ページ）
  - p.7: 一般会計予算総括表（歳出）
  - p.8: 一般会計歳出予算性質別内訳表

## JSON生成
スクリプトで `pdftotext -layout` を使って p.7/p.8 の表を構造化して `naiyo-setsumei.json` を生成する。

```bash
python3 NIHO/gov/parse_overview_pdf.py NIHO/gov/naiyo-setsumei.pdf --out NIHO/gov/naiyo-setsumei.json
```

## ブラウザ表示（インフォグラフィック試作）
- ビューア: `NIHO/gov/viewer/overview.html`
  - 円グラフ: 款別の構成比（令和7）
  - 棒グラフ: 款別の前年差（令和7-令和6）
  - 積み上げ: 選択した款の性質別内訳（比率）

### 開き方
1) `NIHO/gov/viewer/overview.html` を開く  
2) `naiyo-setsumei.json` をファイル入力から選択

（ローカルサーバで開ける場合は自動読み込みも動く）
```bash
cd NIHO/gov && python3 -m http.server 8000
```
ブラウザで `http://localhost:8000/viewer/overview.html`
