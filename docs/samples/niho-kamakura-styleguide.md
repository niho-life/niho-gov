# NIHO kamakura デザインルール

## 1. カラーパレット

### プライマリーカラー
- **オフホワイト/クリーム**: `#F5F5F5` または `#FAFAF9`
  - 背景色として使用
  - 明るく開放感のある雰囲気を演出

### セカンダリーカラー
- **グリーン（緑）**: `#99CC33` または `#A8D233`
  - 日本語テキスト（「リビングに通う」「まちを知る」など）の強調
  - ナビゲーション項目の見出し
  - アクセントカラーとして印象的に使用

### テキストカラー
- **ダークグレー/濃い灰色**: `#555555` または `#666666`
  - 本文テキスト
  - 英語表記やサポートテキスト
  - 読みやすさを優先したニュートラルカラー

- **ライトグレー**: `#999999`
  - サブテキストやメタ情報
  - ナビゲーション
  - より薄い視覚的階層を表現

### アクセントカラー
- **オレンジ/オレンジイエロー**: カレンダーのオープンデイ表示
- **黄緑**: カレンダーのイベント表示
- **灰色**: カレンダーの貸切中表示

## 2. タイポグラフィ

### フォントファミリー
- **本文・見出し**: おそらく `YuGothic` または `Hiragino Sans` などの日本語サンセリフ
  - 清潔で親しみやすい印象
  - 和風と現代的な印象のバランス

### フォントサイズ階層
- **メインタイトル**: 大きめ（おそらく 32-48px）
  - 「暮らしを楽しむシェアリビング」
  
- **セクションタイトル**: 中程度（24-32px）
  - 「NIHOとは」「NIHOでできること」など

- **本文**: 14-16px
  - 読みやすい標準サイズ

- **キャプション/メタ情報**: 12-14px
  - 日付やメタデータ

### フォントウェイト
- **見出し**: Bold（600-700）
- **本文**: Regular（400）
- **サブテキスト**: Regular（400）- ただしカラーでの区別

## 3. 余白・スペーシング

### 原則
- **余裕をたっぷり取る**: ミニマリスト的な設計
- **要素間の距離**: 生息地のように自由で開放感のある配置

### ページ構成
- **セクション間**: 60-100px の上下余白
- **セクション内の内容**: 30-50px の余白
- **要素内部**: 20-30px のパディング

### ナビゲーション
- テキスト「リビングに通う」「単発で借りる」「まちを知る」などの見出しが入り、グルーピング構造を持つ
- グループごとに視覚的な分け目がある

## 4. レイアウト構造

### ナビゲーション
- **左側**: メインナビゲーション（「ABOUT」「SERVICE」「PRICE」「CALENDAR」など）
- **構造化**: 「リビングに通う」「単発で借りる」「まちを知る」の3つのカテゴリに分けられている
- **リンク方式**: テキストリンク + 英語表記（例：「ABOUT」）

### ヘッダー
- ロゴはホームリンク
- 複数のナビゲーショングループ
- ソーシャルメディア（Instagram、LINE）へのリンク（下部に配置）

### コンテンツレイアウト
- **ファーストビュー**: カルーセル/スライドショー
  - 複数の施設写真を自動で遷移表示
  - 前後のボタン、再生ボタン

- **3カラム構成**: 「くつろぐ」「つながる」「いろどる」などの見出し
  - 等幅で配置
  - バランスの取れた構成

- **2カラムレイアウト**: 画像 + テキストの組み合わせ
  - 柔軟性のある構成

### グリッドシステム
- **セクション幅**: フルスクリーンで対応
- **コンテナ**: 左右に余白を持つ
- **段落**: テキストは読みやすい行長（50-70文字程度）

## 5. 全体的な雰囲気・トーン

### デザインコンセプト
- **「もう一つのリビング」**: 家庭的で温かみのある空間
- **ナチュラル & モダン**: 和風と現代的な要素の融合
- **開放感**: 広いホワイトスペース、大きな写真

### ビジュアル要素
- **写真の使用**: 大きく高解像度
  - 実際の施設や人物の写真
  - 温かみと信頼性を演出

- **アイコン**: Google Material Design のアイコン（例：`expand_less`）
  - 矢印（左右移動用）
  - 機能的な記号

### 印象
- **親しみやすさ**: グリーンアクセント、手書きっぽい余白
- **信頼性**: シンプルで透明性のあるデザイン
- **開放性**: パナソニックが運営する堅実さ + 地域密着の温かさ

## 6. 色彩の使い分け

| 要素 | カラー | 用途 |
|-----|--------|------|
| 背景 | オフホワイト | ページ全体 |
| テキスト | ダークグレー | 本文 |
| 日本語見出し | グリーン | 「リビングに通う」などのカテゴリ |
| 英語テキスト | グレー | 見出しのサポート |
| カレンダー（オープンデイ） | オレンジ | スケジュール表示 |
| カレンダー（イベント） | 黄緑 | スケジュール表示 |
| カレンダー（貸切） | 灰色 | スケジュール表示 |

## 7. UI パターン

### ボタン
- **スタイル**: テキストリンク + 矢印アイコン `keyboard_arrow_right`
- **カラー**: グリーン（おそらく同じアクセントカラー）
- **ホバー効果**: 下線などで視覚的フィードバック

### フォーム
- **入力フィールド**: シンプルなテキスト入力
- **チェックボックス**: 「プライバシーポリシーに同意する」
- **ボタン**: 「送信する」（テキストボタン）

### カード/セクション
- **価格プラン**: リスト形式
- **スタッフ紹介**: 画像 + テキスト組み合わせ
- **場所紹介**: スライドショー + キャプション

## 8. 応答性・ブレークポイント

- **デスクトップ**: 1200px以上
  - フルレイアウト、3カラム対応

- **タブレット**: 768px～1200px
  - 調整されたナビゲーション

- **モバイル**: 768px以下
  - ハンバーガーメニュー（ref_44）の存在
  - スタックレイアウト

## 10. 参考資料

**実装の際の注意点:**
- グリーンのアクセントはメリハリをつけるため、日本語の重要なカテゴリ見出しに限定
- ホワイトスペースは「リビング」というコンセプトと相性が良い（開放的な空間）
- 写真は高解像度で、実際の人物や施設を使用することで信頼性を増す
- フォント選びはモダンサンセリフで、日本語と英語の両対応が必須
